# Pre-Calculus_Anki

Enhance your Pre-Calculus learning experience with our curated Anki decks, designed to leverage the power of spaced repetition for effective mastery. Utilizing MathJax, these decks provide precise mathematical notation to ensure clarity and accuracy in your studies.

## Features

- **Curated Anki Decks**: Expertly crafted decks focusing on key Pre-Calculus concepts.
- **MathJax Integration**: Enjoy clear and precise mathematical notation.
- **Spaced Repetition**: Utilize Anki's proven method to enhance retention and understanding.
- **Multi-Platform Support**: Compatible with Anki on various operating systems.

## Setup & Installation

To get started with the Pre-Calculus Anki decks:

1. **Install [Anki](https://apps.ankiweb.net/)**: Ensure you have Anki installed on your device.
2. **Clone the Repository**:
   ```bash
   git clone https://github.com/yourusername/Pre-Calculus_Anki.git
   ```
3. **Import Decks**: Open Anki, navigate to `File > Import`, and select the downloaded `.apkg` files from the `decks` directory.

## Usage

1. Launch Anki on your device.
2. Import the Pre-Calculus decks as described in the Setup section.
3. Start reviewing cards daily to maximize retention using spaced repetition.
